# Projeto de BI: Análise de Vendas 2019

Este repositório contém o código-fonte e os arquivos do projeto prático de desenvolvimento em Business Intelligence (Dashboard no Power BI). 

O projeto segue uma abordagem de desenvolvimento progressivo, dividido em 4 entregas (Sprints) ao longo do semestre. A cada entrega, novas funcionalidades e regras de negócio são adicionadas ao modelo.

## 📁 Estrutura do Repositório (Fase AC1)

* `/data` -> Arquivos de origem (Planilhas Excel).
* `/powerbi` -> Contém o arquivo `.pbix` do Dashboard e a documentação das medidas `DAX` criadas nesta Sprint.
* `/docs` -> Capturas de tela (prints) evidenciando as funcionalidades entregues.

## ⚙️ Como visualizar o projeto localmente

1. Faça o download do arquivo `.pbix` localizado na pasta `/powerbi`.
2. Abra o arquivo no aplicativo **Power BI Desktop**.
3. *Nota:* Caso o Power BI solicite atualização de credenciais ou não encontre a base de dados ao abrir, vá em `Transformar Dados > Configurações da Fonte de Dados` e aponte para o caminho onde você salvou a pasta `/data` em seu computador local.
